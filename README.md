# GPSC Prelims Previous Year Papers – Trend Analysis

## 📌 Overview

This repository contains GPSC (Gujarat Public Service Commission) Prelims previous year question papers in PDF format.

The main purpose of this repository is to analyze previous year papers and identify:

- Frequently asked topics
- Repeated questions and concepts
- Subject-wise question trends
- Important topics
- Topic frequency across years
- Difficulty trends
- Current Affairs trends
- Most important subjects/topics for upcoming GPSC Prelims

This repository is intended to be used with GitHub Copilot for AI-assisted question paper analysis and trend identification.
